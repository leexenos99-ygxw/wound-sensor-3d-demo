# 分子实验室 v2 · 3D 化学教具

一个单文件运行的 3D 化学演示台，三个视图：**SN2 亲核取代机理**、**智能敷料分层结构**、**分子组装（自由搭建 + 实时识别 + 几何整形）**。

核心目标不是"看起来像分子"，而是**每个几何形态都能讲出道理**：键角来自 VSEPR 电子域排斥，键级来自价键约束，孤对电子由价电子数推导。

---

## 一、怎么打开

| 文件 | 用途 | 体积 |
|---|---|---|
| `index.html` | **发布副本**，GitHub Pages 直接读它；内容与离线版逐字节相同 | ~812 KB |
| `dist/molecule-lab-offline.html` | **完全离线版**，three.js 已内联，双击即可用，无网络也能跑 | ~812 KB |
| `dist/molecule-lab.html` | 轻量版，three.js 走 CDN（需联网） | ~150 KB |

`index.html` 和两个 `dist/` 文件都是**构建产物**，由 `node build.mjs` 生成，不手工编辑；要改内容请改 `src/`。
`source/` 是上一代（组装模式之前）的旧链路，保留仅作追溯，已由 `src/` + `build.mjs` 取代。

两版的应用代码逐字一致，只有 three.js 的引入方式不同，构建脚本会自动校验这一点。

推荐使用离线版：拷到 U 盘、发微信、放进答辩电脑都不会挂。

## 二、三个视图

### 1. SN2 亲核取代（默认）
五步机理时间轴：反应物 → 背面进攻 → 过渡态（五配位三角双锥）→ 断键反转 → 产物。
可播放/单步，电子流动箭头可开关。

### 2. 智能敷料分层
四层结构 + 六窗传感阵列示意。

### 3. 分子组装
- **原子托盘**：H / C / N / O / Na / Mg / Cl，CPK 配色，点击即在场景放置
- **成键**：进入成键模式后依次点两个原子；再次点已成的键可删除
- **价键约束**：每个原子维护剩余价键数，超价直接拒绝并红色高亮
- **分子识别**：连通图 + 带标签图同构匹配，命中内置模板显示名称，否则显示分子式
- **几何整形**：成键后自动把整个分子摆成标准构型（0.6 s ease-out 动画），质心归中、抬到 y=1.5
- **孤对电子**：按 `(价电子 − Σ键级)/2` 推导，灰色双点显示
- **解释卡**：实时给出"为什么是这个键角"

## 三、深链参数

| 参数 | 作用 |
|---|---|
| `?mol=CO2` | 直接生成指定分子并即时整形。可选 H2O / CO2 / CH4 / NH3 / C2H4 / C2H6 / C2H2 / HCl / O2 / N2 / Cl2 / H2O2 / CH3OH / C2H5OH / Me2O |

## 四、化学数值从哪来

所有数值集中在 `src/core.js` 顶部，**不许为了视觉对称去改**。

**多重键长（Å）**
C=C 1.34｜C≡C 1.20｜C=O 1.23｜C=N 1.28｜N=N 1.25｜N≡N 1.10｜O=O 1.21
CO₂ 的 C=O 单独取 **1.16**（气态实验值，与羰基的 1.23 不是一回事）

**单键长（Å）**
H-H 0.74｜C-H 1.09｜N-H 1.01｜O-H 0.96｜C-C 1.54｜C-N 1.47｜C-O 1.43｜C-Cl 1.77｜C-Br 1.94｜N-N 1.45｜N-O 1.40｜O-O 1.48｜Cl-Cl 1.99｜Br-Br 2.28｜H-Cl 1.27｜Na-Cl 2.36｜Mg-O 2.10

**键角**
H₂O 104.5°｜NH₃ 107°｜CH₄ 109.5°｜C₂H₄ 平面 sp² 120°｜CO₂ 180°｜C₂H₂ 180°

**孤对电子** = (价电子 − Σ键级) / 2，验算：H₂O 的 O=2、NH₃ 的 N=1、CH₄ 的 C=0、HCl 的 Cl=3。

**角度模型**（`angleForDomains(n, lp)`）
电子域 2 → 180°；3 → 120 − 0.5 × lp；4 → 109.5 − 2.5 × lp。
所以 H₂O 是 4 域 2 孤对 → 104.5°，NH₃ 是 4 域 1 孤对 → 107°，CH₄ 是 4 域 0 孤对 → 109.5°。

> 界面里的分子是**教学示意图，不是实验测量结果**；数值取自公开实验值，几何经过理想化。

## 五、自检与断言

跑自检：`?selftest=1`，或命令行 `node test/core.test.mjs`。

**核心层 20 条（纯逻辑，不依赖浏览器）**

| # | 断言 | 实测 |
|---|---|---|
| 1 | 所有原子坐标 finite | 80 个坐标全部有限 |
| 2 | Cl₂ 键长 1.99 | 1.990 Å |
| 3 | O₂ order=2 且 1.21 | order=2，1.210 Å |
| 4 | N₂ order=3 且 1.10 | order=3，1.100 Å |
| 5 | CO₂ 配位 2、两根双键 | 配位 2，双键 2 根 |
| 6 | CO₂ 1.16 Å / 180° | 1.160 Å / 180.0° |
| 7 | H₂O 键角 104.5° | 104.5° |
| 8 | NH₃ 三个 107° | 107.0° × 3 |
| 9 | CH₄ 六个 109.5° | 109.5° |
| 10 | C₂H₄ 六原子共面 | max\|z\| = 0.0000 |
| 11 | C₂H₄ 键角 ≈120° | H-C-H 120.0°，H-C=C 120.0° |
| 12 | 超价拒绝（O 建第 3 键） | 被拒，原子 4 / 键 2 |
| 13 | 删原子后键数守恒 | 2 − 2 = 0 |
| 14 | 乙醇 ≠ 二甲醚 | 度序列相同=true，同构=否 |
| 15 | H₂O 不误命中 NH₃ / H₂O₂ | 命中 H2O |
| 16 | 整形前后邻接表与键级一致 | 邻接一致，键级一致 |
| 17 | 整形两次坐标一致 | 最大差 0.00e+0 Å |
| 18 | 孤对 H₂O=2 / NH₃=1 / CH₄=0 / HCl=3 | 2 / 1 / 0 / 3 |
| 19 | 键角 104.5 < 107 < 109.5 | 成立 |
| 20 | 模板里每个原子 Σorder ≤ 上限 | 20 个模板全合法 |

**应用层 3 条（需浏览器）**
#21 双键渲染为 2 根圆柱｜#22 三键渲染为 3 根圆柱｜#23 手工搭的 CO₂ 自动升到双键

**#14 是关键**：乙醇 C-C-O-C 与二甲醚 C-O-C-C 的**度序列完全相同**，靠度序列区分会误判；必须用带标签的图同构（Weisfeiler-Lehman 标号 + 回溯映射）才能分开。

## 六、工程结构与构建

```
src/core.js               纯逻辑层（IIFE 挂 globalThis.CHEM，node 可直接跑）
src/app.js                渲染 + 交互 + UI
src/index.template.html   外壳，含 {{THREE}} {{ADDONS}} {{CORE}} {{APP}} 四个占位
build.mjs                 零依赖构建脚本（只用 node:fs），拼装两版并自检
test/core.test.mjs        核心断言运行器
vendor/three.umd.js       three r150 UMD 版（669 KB）
vendor/addons.js          OrbitControls + CSS2DRenderer（已去模块化）
dist/                     产物，勿手改
shots/                    验收截图
```

**改代码只改 `src/` 和 `vendor/`，`dist/` 是产物。**

```powershell
node build.mjs           # 重建两版
node build.mjs --check   # 只校验 src 与 dist 是否同步，不写文件
node test/core.test.mjs  # 跑 20 条核心断言
```

构建脚本内置两条防线：
1. 组装完成后抠掉第一段 `<script>`，比对两版剩余内容是否逐字相等；
2. `--check` 模式发现 dist 落后于 src 时以非零码退出。

`String.replace` 的替换串如果含 `$&`/`$'` 会被当成特殊符吃掉（three 源码里到处是），所以拼装一律用函数替换。

## 七、已知边界

- 只做**单/双/三键**，不涉及芳香、离域、立体手性标记。
- 模板表 20 条，查不到走 VSEPR 兜底，兜底是逐原子角度松弛，不是精确求最优。
- 离子晶体（NaCl、MgO）按单键画，不体现晶格。
- 界面数值是教学示意，不作为实验数据引用。
